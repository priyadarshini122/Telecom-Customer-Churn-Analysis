# Telecom Customer Churn Analysis

## Project Overview
This project analyzes telecom customer data to understand customer churn patterns, identify potential reasons for customer attrition, and explore factors that influence customer retention.

## Tools Used
- Power BI
- Data Analysis
- Data Visualization

## Dashboard Features
- Customer Churn Rate: Churned vs. Retained Customers
- Customer Distribution by Age and Gender
- Customer Tenure Analysis
- Churn by Contract Type
- Customer Distribution by Payment Method
- Total Charges vs. Tenure Analysis
- Total Revenue Distribution

## Business Objectives
- Measure the customer churn rate.
- Identify customer segments with higher churn.
- Analyze the relationship between tenure, contracts, and churn.
- Understand payment-method patterns.
- Support data-driven customer retention strategies.

- Data Cleaning and Preparation
- Exploratory Data Analysis
- KPI Development
- Power BI Dashboard Design
- Business Insights and Data Visualization
